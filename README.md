# Daily Market Report — Prototype

Static HTML/CSS/JS prototype for user testing the redesigned Daily Market Report and atomic article pages. No build step — open any file directly, or serve the folder as-is.

## Pages

- `index.html` — the main prototype: Daily Market Report with AM/PM toggle. This is the root page testers land on.
- `test-links.html` — facilitator-only quick links to every page (not part of the prototype itself — don't send this to testers)
- `ao.html`, `bbsn.html`, `cgs.html`, `gaw.html`, `hsp.html`, `like.html`, `pzc.html`, `snws.html` — individual stock article pages

## Live link

Hosted via GitHub Pages once enabled for this repo (Settings → Pages → Deploy from branch → `main` → `/ (root)`): `https://<your-github-username>.github.io/<repo-name>/` — that URL goes straight to `index.html`, the live prototype.

## Notes

All data (prices, comments, analyst names) is placeholder content for testing purposes only — nothing here reflects real Stockopedia data.
